SNAPYT // PUSH HANDOFF SPECS

Architecture Principles

A remote push routes messages from application backends through platform push services (APNs/FCM) to a specific installation using an opaque device token.

Suggested Registration Record

Field Purpose
account_id Recipient account from authenticated session.
installation_id Unique app installation identity.
provider & target_kind FCM/APNs route & address kind.
target_address Exact opaque device token.
status / invalidated_at Active state and deactivation timestamp.
